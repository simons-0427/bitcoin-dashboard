# Quellen und Nutzungsbedingungen

Die Herkunft einzelner Beobachtungen bleibt über `source_slug`, `source_revision` und `raw_payload_hash` in den CSV-Dateien erhalten. Daten und Bibliotheken erhalten keine pauschale neue Lizenz durch dieses Paket.

| Bestandteil | Herkunft und Hinweise |
| --- | --- |
| Coin Metrics Community BTC | [Coin Metrics Community Data](https://github.com/coinmetrics/data), [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). Nichtkommerzielle Nutzung mit Namensnennung. Dies betrifft auch davon abhängige Berechnungen. |
| Open Bitcoin Metrics | [Open Bitcoin Metrics](https://github.com/diegorllanos/open-bitcoin-metrics), Diego R. Llanos, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Release und Quellzeilen-Hashes bleiben erhalten. |
| Fear & Greed Index | [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/). Quellenangabe beim angezeigten Index erforderlich; die konkreten API-Nutzungsbedingungen gelten weiter. |
| Futures-Open-Interest | [CFTC Commitments of Traders](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm). [CFTC Web Policy](https://www.cftc.gov/WebPolicy/index.htm). Die USD-Umrechnung verwendet Coin-Metrics-Preise mit deren zusätzlichen Bedingungen. |
| EUR/USD-Eingangsreihe | [European Central Bank, Euro foreign exchange reference rates](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html), [ECB copyright and reuse](https://www.ecb.europa.eu/services/disclaimer/html/index.en.html). |
| Weitere Anzeigewährungen | Historische Devisenkurse aus dem separat installierten Weltmarkt-Dashboard; dessen Quellen- und Lizenzangaben gelten. |
| Lokal berechnete Kennzahlen | Berechnungen aus den dokumentierten Eingangsreihen. Die Bedingungen der jeweiligen Eingangsquellen gelten weiterhin. |
| Chart.js | [Chart.js](https://github.com/chartjs/Chart.js), MIT-Lizenz. Lizenztext in `dashboards/bitcoin/assets/vendor/Chart.js-LICENSE.md`. |
| CA-Zertifikatspaket | Mozilla-Zertifikatsbestand über curl. Mitgelieferte Hinweise: `dashboards/bitcoin/includes/bitcoin/CA-LICENSE.txt`. |
| Schriftarten | Google Fonts: Syne und DM Sans werden vom Browser extern geladen. Sie sind nicht Bestandteil des Archivs. |
